# CercArtigiano

Benvenuto nel repository di CercArtigiano.

## Ultimi Aggiornamenti Inclusi (`v1.1`)
- **Fix Privacy Profilo:** Corretto il bug per cui le impostazioni di privacy dell'utente e del professionista si sovrapponevano.
- **AI Address:** Integrazione con Gemini Flash 2.5 per l'inserimento e l'autocompletamento intelligente degli indirizzi.
- **Chat Condivise:** Sistema di messaggistica integrato per mettere in comunicazione i professionisti e i clienti per i dettagli di un preventivo.
- **Backend Firebase:** Gestione migliorata della distribuzione e dei log applicativi.

## Deploy Automatizzato (GitHub Actions)
Questo progetto è configurato per essere distribuito automaticamente su Firebase Hosting tramite GitHub Actions ogni volta che viene effettuato un push sul branch `main`.

Se stai effettuando la sincronizzazione da Google AI Studio, assicurati di inviare le modifiche (Sync to GitHub) e GitHub si occuperà del resto!
